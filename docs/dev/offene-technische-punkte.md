# Open technical points (`TODO(offene-frage)`)

Consolidated list of every place where the implementation relies on an assumption that must be verified on the
FS25 prototype. Sources in the technical concept (`docs/concept/Technisches_Konzept_V6.md`): chapter
**„Offene technische Fragen“** (file bridge) and chapter **„Offene technische Punkte“** (end of the document).
Each entry names the chosen best-effort solution, the fallback and the code location. In the code the places
are marked `TODO(offene-frage)` (`grep -rn "TODO(offene-frage)" mod backend`).

| # | Question | Concept reference | Chosen solution / fallback | Code location |

The mod writes directly (`atomicWriteMode = "direct"`); the backend discards incomplete JSON and retries. | `mod/FS25_RPSim/src/util/FileIO.lua` (`write`), `mod/FS25_RPSim/src/bridge/Config.lua` |
