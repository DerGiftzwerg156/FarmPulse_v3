# Concept documents (source of truth)

`Fachliches_Konzept_V3.md` (functional concept) and `Technisches_Konzept_V6.md` (technical concept) are the
binding functional and technical specification of this project. Whenever code and concept disagree, the
concept wins; deliberate deviations are never made silently but go through [`QUESTIONS.md`](../../QUESTIONS.md)
first. `Arbeitspakete.md` is the work-package plan used to implement the concept step by step, and
`../design-reference/Dashboard.html` is the visual reference for the Angular design system. All files in
this folder are imported unchanged.
