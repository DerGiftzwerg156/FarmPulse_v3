# FS25 KI-Rollenspiel-Simulation (FarmPulse)

Ein Begleit-Tool für Farming Simulator 25, das dem Hof echte Ansprechpartner gibt: KI-gestützte Charaktere (Bank, Nachbarn, Dorfbewohner, Mitarbeiter) kommunizieren per Mail und Anruf, während alle Zahlen von einer deterministischen Fakten-Ebene berechnet werden.
